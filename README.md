# 🚗 AutoFlex Sentiment Analysis

## Descripción

Proyecto de Machine Learning enfocado en analizar opiniones de clientes
y clasificarlas según sentimiento:
- Bueno
- Malo
- Información

## Objetivo

Desarrollar un modelo capaz de identificar automáticamente la percepción
del cliente utilizando técnicas de Procesamiento de Lenguaje Natural.

## Tecnologías utilizadas

- Python
- Pandas
- NLTK
- Scikit-Learn
- TF-IDF

## Proceso

1. Limpieza del texto
2. Tokenización
3. Eliminación de stopwords
4. Lemmatización
5. Vectorización TF-IDF
6. Entrenamiento del modelo
7. Evaluación

## Resultados

Accuracy:
97.5%
